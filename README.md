Introduction the primary rensponsibitities of an operating system.

-An operating system is the most important software on a computer. It acts as a bridge between users, apps, and physical hardware. Its main jobs are managing system resources, running prog,    and keeping data safe.

Explain the fundamental difference between physical Hardware and software instructions.

-Physical hardware is the tangible, electronic machinery that you can touch, such as the CPU and memory. Software instructions are intangible sets of digital code and logic that tell that       machinery what tasks to perform.

-Hardware provides the physical power, while software provides the directions.

Identify and briefly describe 5 internal hardware components

-Motherboard: The main circuit board. It connects all parts so they can talk to each other.

-CPU: The brain of the computer. It does math and runs program instructions.

-RAM: Short-term memory. It holds data for apps that are open right now and clears when the PC turns off.

-Storage (SSD or HDD): Long-term memory. It saves your files and apps even when the power is off.

-GPU: The GPU performs mathematical calculations at lightning speed to turn computer data into the images, videos, and games you see on your screen.

Explain the key operational difference between RAM (volatile) and an SSD (non-volatile storage).

-RAM is fast, temporary working memory that loses all data when the power turns off. An SSD is slower, permanent storage that keeps your files safe even when the computer turns off.
